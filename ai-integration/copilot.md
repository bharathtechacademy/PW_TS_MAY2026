# What is Co-Pilot? 
Copilot is an AI-powered coding agent available as an extension in the IDE. 

## How Github Copilot will work and what are all the different features of Github Copilot ?

GitHub Copilot is powered by backend LLMs, and 
- it is going to understand your current file or your current project structure. 
- It will understand existing framework patterns. 
- It will understand the comments written by the user to generate the code. 
- It will understand the libraries imported within the project and suggest the code according to the existing libraries. 

## Different features of Copilot ?

1. Inline Code Suggestions 
Whenever we are going to write the code, it is going to fill the remaining part of that particular code. 

2. Copilot chat (Ask mode) 
Co-pilot Ask Mode is all about providing the suggestions but not implementing in your project. 

3. Copilot chat (Agent mode) 
Co-pilot agent mode is all about providing the suggestions and updating the code inside our program. 

4. Copilot chat (Plan mode) 
Co-Pilot Plan Mode is all about creating an execution strategy before making changes in the code. Meaning, Co-Pilot is going to analyze the requirement, break it into multiple steps, then it is going to give you a strategy to complete. 

5. Test script generation 
It can actually generate all the possible test cases, assertions, and reusable methods during the automation development process. 

6. Can explain the code
It can explain each and every line of code and the background information about why we have added it and why it is needed, etc. 

7. Copilot can generate documentation. 
For each and every line of code and each and every common method, it can generate standard documentation comments. 

8. Copilot supports Agents and MCP integrations. 
For regular day-to-day tasks, Copilot is going to help us to maintain custom agents, and also it is going to help us to integrate the MCP server to connect with the tools.
