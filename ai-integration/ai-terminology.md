## Conversational AI tools 
Conversational AI tools are all about a set of web applications or desktop applications integrated with AI models, and these applications are going to allow us to chat with what ever the problem statements we have.

We are going to send a prompt, and from these applications we will be able to get the single response. 

Examples : Charge GPT, Gemini, Claude, etc. 

### How Convergational AI tools will work in the background ?
Generally, when we are going to send a prompt from the UI by using whatever the chat window provided by the tool , The prompt will be shared with the backend API integrated into the web application. Then the API is going to share this information with the backend LLM. 



## Co-Pilots

Co-pilot is an AI assistant or a plug-in installed inside our IDE. Especially, it is going to help us to complete the coding-related task, and also it is going to help you to build the code for your new requirements. 

Example : GitHub Copilot , Claude , tab nine etc..

What are all the benefits we are going to get with Co-Pilots? 

Co-pilot can write the code for the new functionality based on the existing code. 
Co-pilot can explain the existing code written by another person in your framework. 
Co-pilot can debug the issue whenever there is any error identified in your project. 
Co-pilot can perform unit testing based on the existing code. 
Co-pilot can refactor the code and also it can correct the format. 
Co-pilot can help us to learn the new concepts introduced in the programming language, etc. 

## Coding Assistants

Coding Assistant is an IDE integrated with AI models by default. 

Example : Cursor, windsurf, Claude Code, anti-gravity, codex, etc. 

## LLM ( Large Language Model )
Large Language Model is all about the AI model that is trained with structured and unstructured data collected from the internet. 

Example : GPT 5.4 , Gemini 3.5 Flash etc..

## RAG ( Retrieval Argument Generation )
RAG is a Framework Used in the AI models. RAG is a framework that is going to help us to identify the relevant information from the trained content inside the LLM. RAC is always going to share the details to the LLM about particular information and the context and the specific configurations, and then it will get the exact answer that the user is expected. 

## MCP (Model Context Protocol )
MCP is an open-source protocol that allows AI models and agents to connect with external tools or applications or databases or files, etc. 

Examples : Playwright MCP , Git MCP, Chrome MCP etc..

## CLI (Command line interface )
CLI is a command line interface designed for coding agents to control the browser using shell commands. 

## Agent 
Agent is all about a file with a set of instructions provided by the user to complete a specific task.
