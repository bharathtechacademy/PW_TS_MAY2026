# Day-to-day tasks related to software testing. 

1. Requirement analysis for the new user stories and generate test plan. 
2. Test Design for the New User Story 
3. Manual test execution for each and every test case. Collecting the proof of testing and identifying the defects and logging the defects in Jira or ADO 
4. Preparing end of test report after completing the test execution and analyzing the overall execution flow and test results 
5. Pair release notes for all the user stories that need to be released. 
6. Identify regression cases and performing the automation feasibility analysis for the new test cases. 
7. Automate the new regression cases by following the existing automation framework. 
8. Maintaining the automation test cases and fixing the errors within the existing automation test scripts 
9. Review the PR when someone is going to write new code by following all the standards provided by our organization. 
10. Create a brand new framework with multiple utilities according to the new application to automate the scene.
