Planning Guidance

  • Prioritize P1 Regression automation for popup display, header/content contracts, Necessary disabled state, and Allow all / Deny close + persistence flows.
  • Include selective consent (Allow selection) and Show details expand in the standing regression pack due to compliance and UX risk.
  • Keep layout/responsive and rapid-click edge cases in Functional for the story validation cycle unless defects recur.
  • Automation backlog should start with clean-session popup appearance and post-consent refresh persistence checks.
